# Консольний діалог з OpenAI

Простий Python скрипт для ведення діалогу з OpenAI через консоль.


1. Створіть віртуальне середовище (якщо ще не створено):
```bash
python -m venv venv
```

2. Активуйте віртуальне середовище:

**Windows (PowerShell):**
```powershell
.\venv\Scripts\Activate.ps1
```

**Windows (Command Prompt):**
```cmd
venv\Scripts\activate.bat
```

**Linux/Mac:**
```bash
source venv/bin/activate
```

3. Встановіть залежності:
```bash
pip install -r requirements.txt
```

4. Створіть файл `.env` в корені проекту і додайте туди ваш API ключ OpenAI:
```
OPENAI_API_KEY=your_api_key_here
```

**Примітка:** Файл `.env` вже додано до `.gitignore`, тому ваш ключ не потрапить у git.

Альтернативно, ви можете встановити змінну середовища вручну:
- **Windows (PowerShell):** `$env:OPENAI_API_KEY="your_api_key_here"`
- **Windows (CMD):** `set OPENAI_API_KEY=your_api_key_here`
- **Linux/Mac:** `export OPENAI_API_KEY=your_api_key_here`

## Використання

Запустіть скрипт:
```bash
python chat.py
```

Введіть ваше повідомлення та натисніть Enter. Для виходу введіть `exit`, `quit`, `вихід` або `q`.

## Збереження діалогів

Всі діалоги автоматично зберігаються в папку `dialogues/` у форматі JSON. Кожен діалог зберігається у окремому файлі з назвою `dialogue_YYYY-MM-DD_HH-MM-SS.json`, де вказана дата та час створення.

Діалог зберігається автоматично при:
- Нормальному завершенні (команда `exit`, `quit`, `вихід` або `q`)
- Перериванні програми (Ctrl+C)

Формат збереження діалогу:
```json
{
  "timestamp": "2024-01-15T14:30:00",
  "messages": [
    {
      "role": "user",
      "content": "Привіт!"
    },
    {
      "role": "assistant",
      "content": "Привіт! Чим можу допомогти?"
    }
  ]
}
```

## Вижимки діалогів

Для кожного діалогу автоматично створюється вижимка (extract) у папці `summaries/`. Вижимка містить структуровану інформацію про діалог у форматі JSON.

Файли вижимок мають назву `extract_YYYY-MM-DD_HH-MM-SS.json` та містять:

```json
{
  "facts": [
    "факт 1",
    "факт 2"
  ],
  "people": [
    "Ім'я людини 1",
    "Ім'я людини 2"
  ],
  "objects": [
    "об'єкт 1",
    "об'єкт 2"
  ],
  "date": "2024-01-15"
}
```

**Поля вижимки:**
- `facts` - масив фактів, згаданих у діалозі
- `people` - масив імен людей, згаданих у діалозі
- `objects` - масив об'єктів, предметів, речей, згаданих у діалозі
- `date` - дата діалогу у форматі YYYY-MM-DD

Вижимка створюється автоматично після збереження діалогу за допомогою OpenAI API для аналізу та структурування інформації.

## Збереження Embeddings

Для **кожного факту, людини та об'єкта** з вижимки автоматично генеруються та зберігаються embeddings (векторні представлення) у SQLite базі даних.

**Розташування:**
База даних зберігається в окремій папці `embeddings_db/` у файлі `embeddings.db`.

**Що таке embedding?**
Embedding - це числовий вектор, який представляє семантичне значення тексту. Він дозволяє знаходити схожі діалоги, виконувати семантичний пошук та інші операції з векторними даними.

**Embeddings для фактів, людей та об'єктів:**
- Зберігаються в таблиці `entity_embeddings`
- Основні поля:
  - `dialogue_id` - до якого діалогу належить сутність
  - `date` - дата діалогу
  - `entity_type` - тип сутності: `fact`, `person`, `object`
  - `entity_text` - текст факту / імені / об'єкта
  - `embedding` - JSON рядок з вектором embedding

**Модель embedding:**
Використовується модель `text-embedding-3-small` від OpenAI, яка створює 1536-вимірний вектор для кожної сутності (факт / людина / об'єкт).

**Використання:**
Embeddings зберігаються автоматично після збереження діалогу. База даних створюється автоматично при першому запуску програми в папці `embeddings_db/`.

## Примітки

- Скрипт використовує модель `gpt-3.5-turbo` за замовчуванням
- Відповіді відображаються в реальному часі (streaming)
- Історія розмови зберігається протягом сесії
- Всі діалоги автоматично зберігаються в папку `dialogues/`
- Для кожного діалогу автоматично створюється вижимка в папці `summaries/`
- Embeddings зберігаються в SQLite базі даних `embeddings_db/embeddings.db`
